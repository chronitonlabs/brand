# Chroniton Labs brand

Logos, colours and brand guidelines for Chroniton Labs and its projects. Use these files when you write about, present or link to a Chroniton Labs project. See [STYLE-GUIDE.md](STYLE-GUIDE.md) for how to use them.

## Contents

| Folder | What is in it |
|---|---|
| [`chronitonlabs/`](chronitonlabs/) | The Chroniton Labs mark, lockup, avatar and banner |
| [`chronitondb/`](chronitondb/) | The ChronitonDB mark, lockup, avatar and social preview image |
| [`prompts/`](prompts/) | The design briefs used to produce the artwork |

### Chroniton Labs

| File | Use |
|---|---|
| `chroniton-labs-lockup-light.svg` | Mark and name, for light backgrounds |
| `chroniton-labs-lockup-dark.svg` | Mark and name, for dark backgrounds |
| `chroniton-labs-mark-light.svg` | Mark only, for light backgrounds |
| `chroniton-labs-mark-dark.svg` | Mark only, for dark backgrounds |
| `chroniton-labs-avatar-512.png` | Mark on a solid charcoal square, for avatars |
| `chroniton-labs-banner.svg`, `chroniton-labs-banner-1600x400.png` | Banner, 1600 by 400, for the top of pages |

### ChronitonDB

| File | Use |
|---|---|
| `chronitondb-lockup-light.svg` | Mark and name, for light backgrounds |
| `chronitondb-lockup-dark.svg` | Mark and name, for dark backgrounds |
| `chronitondb-icon-light.svg`, `chronitondb-icon-light-512.png` | Mark only, for light backgrounds |
| `chronitondb-icon-dark.svg`, `chronitondb-icon-dark-512.png` | Mark only, for dark backgrounds |
| `chronitondb-icon-charcoal-512.png` | Mark on a solid charcoal square, for avatars |
| `chronitondb-social-preview.png` | Social preview card, 1280 by 640 |

Use the SVG files wherever you can. They stay sharp at any size.
