# Chroniton Labs brand

Logos, colours and the style guide for Chroniton Labs and its projects. Use these files when you write about, present or link to a Chroniton Labs project. See [STYLE-GUIDE.md](STYLE-GUIDE.md) for how to use them.

## Contents

| Folder | What is in it |
|---|---|
| [`chronitondb/`](chronitondb/) | The ChronitonDB logo, icon, avatar and social preview image |
| `chronitonlabs/` | The Chroniton Labs logo and banner (coming soon) |

### ChronitonDB

| File | Use |
|---|---|
| `chronitondb-lockup-light.svg` | Icon and name, for light backgrounds |
| `chronitondb-lockup-dark.svg` | Icon and name, for dark backgrounds |
| `chronitondb-icon-light.svg`, `chronitondb-icon-light-512.png` | Icon only, for light backgrounds |
| `chronitondb-icon-dark.svg`, `chronitondb-icon-dark-512.png` | Icon only, for dark backgrounds |
| `chronitondb-icon-charcoal-512.png` | Icon on a solid charcoal square, for avatars |
| `chronitondb-social-preview.png` | Social preview card, 1280 by 640 |

Use the SVG files wherever you can. They stay sharp at any size.
