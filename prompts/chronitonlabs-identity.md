Design an identity for Chroniton Labs, the GitHub organisation that hosts ChronitonDB and, over time, other open source projects.

- Chroniton Labs is an umbrella for several open source projects. ChronitonDB, the database you designed a logo for earlier, is the first, and there will be others.

- Same audience and tone as before: engineers and operators, technical, calm, trustworthy. No mascot, no stock imagery.
- AxonOps is the steward, but the identity must not carry AxonOps branding.

Brand rules from the ChronitonDB logo:

Deliverables:
1. A Chroniton Labs mark on its own, square. It becomes the GitHub organisation avatar, shown as small as 32 pixels with rounded corners. Provide it on a solid charcoal background as a 512 by 512 PNG, plus transparent light and dark SVG variants.
2. A horizontal lockup: the mark followed by the wordmark "Chroniton Labs", light and dark SVG variants on transparent backgrounds.
3. A banner for the top of the organisation's GitHub page: 1600 by 400 pixels, PNG, on charcoal so it works in GitHub's light and dark themes. It shows the Chroniton Labs lockup. Show three directions first, so I can pick one before you refine it.
