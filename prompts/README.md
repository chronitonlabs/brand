# Design prompts

The briefs given to Claude Design to produce the logos and images in this repository. Start from these when you need new artwork, such as a mark for a new project, so it follows the same brief and the [brand guidelines](../STYLE-GUIDE.md).

| Prompt | Produced |
|---|---|
| [`chronitondb-logo.md`](chronitondb-logo.md) | The ChronitonDB mark and lockup |
| [`chronitondb-social-preview.md`](chronitondb-social-preview.md) | The ChronitonDB social preview card |
| [`chronitonlabs-identity.md`](chronitonlabs-identity.md) | The Chroniton Labs mark, lockup, avatar and banner |
| [`project-logos.md`](project-logos.md) | The ChronitonMQ, CQLAI and CQL Workbench marks, lockups and social preview cards |

Each design came back as three directions, and the chosen one was refined. The brand guidelines were produced alongside the Chroniton Labs identity.
